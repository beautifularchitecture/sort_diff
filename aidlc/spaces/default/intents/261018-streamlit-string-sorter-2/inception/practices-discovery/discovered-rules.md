## Mandated

- ALWAYS check every sort result for accuracy against the expected result and report the number of steps taken (accuracy and step counts are stated requirements of this app).
- ALWAYS run the sort in the backend when the UI button is pressed and return the result to the frontend.
- ALWAYS deploy to production automatically whenever a change merges to `main` (the human's affirmed choice, departing from the org default).

## Forbidden

- NEVER use a sorting algorithm other than bubble sort, selection sort, or quick sort in this first step.
